# 🎉 Web Ucapan Ulang Tahun Interaktif

Sebuah website ucapan ulang tahun ke-18 yang manis, interaktif, dan penuh kejutan untuk seseorang yang spesial. Dibuat dengan cinta menggunakan **HTML5, CSS3, dan Vanilla JavaScript**.

---

## ✨ Fitur-Fitur Utama

1. **💌 Layar Pembuka "Open Me" (Welcome Gate)**
   * Menampilkan amplop bergoyang interaktif sebelum halaman utama terbuka untuk memberi sensasi penasaran.
2. **🎶 Pemutar Musik Latar (Background Music)**
   * Musik otomatis berputar begitu tombol *"Open Me"* ditekan, lengkap dengan tombol kontrol *Play / Pause*.
3. **🎊 Hujan Confetti Meriah**
   * Kertas warna-warni meledak otomatis saat halaman dibuka dan dapat ditembakkan kembali lewat tombol khusus.
4. **🌌 Langit Malam Berbintang (Twinkling Stars)**
   * Latar belakang malam bertabur 70+ bintang kecil yang berkedip lembut secara acak.
5. **🖼️ Foto Berbingkai & Efek Hover**
   * Foto berbentuk lingkaran dengan bingkai emas yang membesar dan miring halus saat disentuh kursor.
6. **💬 Kartu Ucapan 3D Melayang**
   * Kartu pesan dengan kombinasi warna favorit masing-masing yang terangkat ke atas saat kursor mouse menyentuhnya.
7. **📱 Tampilan Responsif (Mobile-Friendly)**
   * Tampilan otomatis menyesuaikan layar saat dibuka lewat handphone (WhatsApp/Browser HP).

---

## 🛠️ Teknologi yang Digunakan

* **HTML5**: Struktur semantik halaman web.
* **CSS3**: Tata letak Flexbox, animasi `@keyframes`, transisi halus, dan Media Queries untuk responsivitas HP.
* **Vanilla JavaScript**: Manipulasi DOM, logika generator bintang & confetti, kontrol audio, dan transisi layar pembuka.

## 🚀 Cara Menjalankan Secara Lokal

1. Salin (*clone*) repository ini:
   ```bash
   git clone https://github.com/USERNAME/web-ultah.git
   ```
2. Klik dua kali file **`index.html`** untuk membukanya langsung di browser favoritmu (Chrome, Edge, Firefox, dll).
3. Klik tombol **"Open Me ✨"** dan nikmati kejutannya!
